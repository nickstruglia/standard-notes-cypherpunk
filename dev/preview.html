Read me first

Plain notes for a green screen. Body text stays soft mint for long reading; bright green is kept for links, focus and the things you act on. Errors still look like errors.

Principles

  • Keys stay offline. Copies are verified, not assumed.
  • Everything that leaves this device is encrypted first.
  • Tag notes like #offline so they are easy to find in an emergency.
Privacy is necessary for an open society in the electronic age.Eric Hughes, A Cypherpunk's Manifesto (1993)

Before a release

  • Verify the signature on the download
  • Rotate the backup passphrase
  • Restore from the offline copy
  • Shred the old drive

Run sha256sum --check before opening anything you downloaded, and see the install notes for this theme.

# check a download before trusting it
sha256sum --check SHA256SUMS
gpg --verify release.tar.gz.asc release.tar.gz
KEY_ID="ed25519/4F2A" ; echo $KEY_ID

Install

Cypherpunk is the main theme. Rain and Scanlines are layers: switch them on over Cypherpunk, or over any other theme.

Desktop and phone apps

  1. Open Preferences › Plugins and find Install Custom Plugin.
  2. Paste a link, choose Install, then Install again to confirm. Repeat for each layer you want.
  • Cypherpunkhttps://nickstruglia.github.io/standard-notes-cypherpunk/ext.json
  • Rainhttps://nickstruglia.github.io/standard-notes-cypherpunk/rain/ext.json
  • Scanlineshttps://nickstruglia.github.io/standard-notes-cypherpunk/scanlines/ext.json
  1. Open the palette menu at the bottom of the sidebar and pick Cypherpunk. The layers turn on and off in the same menu.

Updates arrive by themselves: phones load the theme from this site, and the desktop app checks for a new version when it starts.

Web app

The web app can't install plugins from a link. If you're signed in, install on a desktop or phone and the themes sync to the web app. Otherwise, import them from a small backup file:

  1. Download cypherpunk-import.json
  2. Open Preferences › Backups › Import backup and choose the file, then pick the themes from the palette menu.

Used the file in the desktop app? Restart it once before choosing the theme.
